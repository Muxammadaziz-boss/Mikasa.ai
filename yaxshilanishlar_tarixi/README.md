# Mikasa AI — Yaxshilanishlar Tarixi

Har bir hujjatda quyidagilar tushuntirilgan:
1. **Muammo nima edi? (Oldingi holat)**
2. **Nima uchun xato edi? (Sabab)**
3. **Qanday tuzatildi? (Yangi holat)**
